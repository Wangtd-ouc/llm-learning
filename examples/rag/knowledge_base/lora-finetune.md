# LoRA 低秩微调

LoRA（Low-Rank Adaptation，低秩适配）是一种高效的参数微调方法，2021 年由微软研究院提出。

## 核心思想

大模型的全量微调需要更新所有参数，成本极高。LoRA 的做法是：冻结原始模型权重，在模型的部分线性层旁边插入两个很小的低秩矩阵 A 和 B。训练时只更新这两个小矩阵，矩阵乘积 A×B 的维度与原始权重相同，最终效果等价于在原始权重上加一个低秩增量。

例如 Qwen2.5-7B 有约 70 亿参数，而 LoRA 只训练约 0.1% 到 1% 的参数，显存和训练时间大幅下降。

## QLoRA

QLoRA 是 LoRA 的进一步优化：把原始模型权重量化到 4-bit（例如 NF4 格式）加载，只对 LoRA 部分保持高精度训练。这样一张消费级显卡就能微调 7B 甚至 13B 模型。

## 什么时候用微调

微调适合以下场景：让模型学习固定的输出格式（例如 JSON）、模仿特定的语气风格、学会私有领域的术语和规范。如果只是想让模型知道一些新事实，优先用 RAG，因为微调“记新知识”容易产生幻觉且成本高。

## 微调的数据格式

最常用的监督微调（SFT）数据是“指令-回答”对，例如 JSONL 格式：

```json
{"instruction": "把句子翻译成英文", "input": "今天天气很好", "output": "The weather is nice today."}
```

数据质量比数量更重要：几百条高质量、格式统一的数据，往往好过几万条脏数据。

## 评估

微调后必须用“训练时没见过的测试集”评估，不能只看训练集损失。常用方法包括人工抽检、用更强模型打分、以及跑一组固定评测题（如中文通用评测 C-Eval）。
