# Transformer 架构要点

Transformer 是现代大语言模型（LLM）的基础架构，由 Google 在 2017 年发表的论文《Attention Is All You Need》中提出。

## 自注意力机制

Transformer 的核心是自注意力（Self-Attention）。它让序列中的每个 token 都能“看到”其他所有 token，并计算彼此的相关程度。注意力权重决定了生成下一个词时，模型更关注上下文里的哪些内容。

多头注意力（Multi-Head Attention）把注意力分成多个“头”，每个头学习不同的关注模式，例如一个头关注语法关系，另一个头关注指代关系。论文中使用了 8 个注意力头。

## 编码器与解码器

原始 Transformer 由编码器（Encoder）和解码器（Decoder）两部分组成。编码器负责理解输入，解码器负责生成输出。现代 LLM 大多只使用解码器（Decoder-only），例如 GPT 系列和 Qwen 系列。

解码器在生成时使用掩码（Mask），保证每个位置只能看到它之前的 token，这叫做因果掩码（Causal Mask），是自回归生成的基础。

## 位置编码

注意力机制本身不包含位置信息，所以需要额外加入位置编码（Positional Encoding）。原始论文使用正弦函数的位置编码；现代模型更多使用旋转位置编码（RoPE），它在数学上把“相对位置”信息编码进注意力计算，是目前主流选择。

## 为什么需要海量参数

LLM 的“智能”来自预训练阶段在海量文本上学习统计规律。参数量越大、训练数据越多，模型能记住和泛化的模式就越复杂。例如 Qwen2.5 系列从 0.5B 到 72B 不等，更大的模型通常推理能力更强，但推理成本也更高。

## 上下文窗口

上下文窗口（Context Window）是模型一次能处理的 token 总数，包括输入和输出。小模型的窗口通常为 4K 到 32K token，大模型可达 128K 甚至更长。超出窗口的内容会被截断，这是 RAG 出现的重要原因之一。
