## 四、3 天学习计划（建议）

### 第 1 天：建立框架 + RAG（约 1.5 小时）

1. 读 `docs/01-llm基础框架.md`（20 分钟）；
2. 跑 `python3 examples/practice/quiz.py` 摸底（10 分钟）；
3. 读 `docs/02-RAG.md`，跑 `rag_demo.py` 和 `rag_embed_demo.py`（30 分钟）；
4. 跑 `evaluate_rag.py`，看懂评估报告（15 分钟）。

### 第 2 天：Agent + 微调（约 1.5 小时）

1. 读 `docs/03-Agent.md`，跑 `agent_demo.py` 和 `agent_tools_demo.py`（30 分钟）；
2. 读 `docs/04-微调.md`，复跑 `finetune_lora_mlx.py`（20 分钟，模型已缓存）；
3. 读 `docs/05-综合项目.md`，跑 `assistant.py`（30 分钟）；
4. 跑 `evaluate_agent.py` 看 6/6 报告（10 分钟）。

### 第 3 天：动手改造 + 最终验收（约 1.5 小时）

1. 按 `docs/07-动手改造指南.md` 给综合示例加一个自己的工具（例如“查你常看的某类数据”），或往知识库加一篇自己的文档（45 分钟）；
2. 跑 `evaluate_agent.py` 确认新用例通过（15 分钟）；
3. 闭卷重做 `quiz.py`，目标 ≥16/20（20 分钟）；
4. 跑 `verify_all.py` 确认全绿，并把输出留存为证据（10 分钟）。
