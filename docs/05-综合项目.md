# 综合项目：把 RAG、Agent、微调组合成一个系统

> 目标：理解三者如何配合，并看懂 `examples/assistant/assistant.py` 的组合方式。

## 1. 三者的分工（再强调一次）

| 技能 | 解决什么问题 | 类比 |
|---|---|---|
| RAG | 模型“不知道”的资料 | 给员工发一份参考资料 |
| Agent | 模型“做不到”的动作 | 给员工配上计算器、电话、数据库 |
| 微调 | 模型“不听话”的格式/风格 | 给员工做岗位培训 |

生产系统中的典型 LLM 应用，几乎都是这三者的组合，而不是单点。

## 2. 组合方式：把 RAG 变成 Agent 的一个工具

`examples/assistant/assistant.py` 的做法是：把“检索知识库”本身注册成 Agent 的一个工具 `search_knowledge()`。

于是模型面对问题时，会自己判断：

- 知识类问题 → 调 `search_knowledge()`（内部就是 RAG 的检索）；
- 计算类问题 → 调 `calc()`；
- 组合问题 → 连续调多个工具；
- 需要时效信息 → 调 `get_current_time()`。

这就是“Agent 外壳 + RAG 内胆”的架构，也是 Dify、Coze 等平台里最常见的工作流。

## 3. 微调在组合里放在哪

微调不参与“运行时”的检索和工具调用，它改变的是模型本身的行为：

- 让模型更稳定地输出 Agent 需要的格式（例如“行动: 工具名(参数)”）；
- 让模型学会业务领域的输出模板；
- 让模型少说“我做不到”（示例里模型曾误说无法访问本地时间，更稳的模型 + 明确提示词能减少这类问题）。

所以组合系统的开发顺序建议是：先 RAG + Agent 跑通 → 发现格式不稳再微调 → 微调后再回测 Agent 循环。

## 4. 从示例到生产

示例为了可复现做了简化，生产化时有几个关键升级：

| 环节 | 示例 | 生产 |
|---|---|---|
| 检索 | TF-IDF + 纯 Python | 嵌入模型 + 向量数据库 + 重排 |
| 工具调用 | 文本协议（正则解析） | 模型原生 Function Calling |
| Agent 循环 | 手写 while | LangGraph / OpenAI Agents SDK 等框架 |
| 模型 | 本机 qwen3.5:4b | 按成本/质量选型或自部署 |
| 微调部署 | mlx_lm server | GGUF/Ollama、vLLM 等推理服务 |

## 5. 评估一个综合系统

分三层看：

1. **工具层**：工具是否稳定执行（错误率、超时）；
2. **决策层**：模型是否选对工具（该检索时检索、该计算时计算）；
3. **输出层**：最终回答是否准确、是否带出处、格式是否达标。

每一层都要有测试用例，改任何一环（提示词、模型、工具）都重跑一遍。

## 6. 动手练习

1. 运行 `examples/assistant/assistant.py`，观察四个问题分别触发了哪些工具；
2. 给综合示例新增一个工具（例如“查汇率”，用模拟数据即可），并加一个问题验证；
3. 把 `search_knowledge` 的 Top-K 改成 5，观察回答质量和耗时变化；
4. 进阶：把 `examples/finetune` 微调出的模型接入综合示例（`--model` 参数），对比格式稳定性。

## 7. 实测：微调模型接入综合示例（2026-08-28）

`assistant.py` 已支持 OpenAI 兼容接口（`--api openai --base-url ...`）。我们用微调后的 Qwen2.5-0.5B（只训练了 6 条“公司介绍”数据）跑了一次知识问答，结果是：

```text
问题：LoRA 主要微调的是什么参数？
[第 1 步] 模型：用一句话介绍这家公司
[第 2 步] 模型：用一句话介绍这家公司
...（8 步全部重复这句话，未调用任何工具）
```

链路本身是通的（综合示例成功调用了微调模型服务），但结论非常有价值：

- **微调会窄化模型行为**：这个模型只会“公司介绍”一种格式，面对 Agent 指令不会输出“行动: 工具名(参数)”；
- **小模型做 Agent 需要“喂格式”**：如果要让微调模型参与 Agent 循环，微调数据里必须包含工具调用格式的样本（`行动: xxx` / `回答: xxx`），否则它不“知道”该怎么当 Agent；
- **模型选择看任务**：通用 Agent 任务用通用强模型（如 qwen3.5:4b），微调模型用在“固定格式输出”的专用任务上更合适。

这是“微调学行为”这一课最直观的实证：**你教它什么，它就只会什么。**
